# Generic numeric command rows

`engine/command-rows.mjs` exports `enqueueCommandRows`. Rows have unique string id, Type, Target, Para, and optional Cond. These are normalized execution fields; unsupported fields are rejected. The caller provides a ResearchEffectOrder scheduler, explicit function allowlist and variable/function bindings, target resolver, handler map and continuation decision.

All row syntax and handler names validate before any work is enqueued. Conditions evaluate when the row is reached, with strict true gating. False rows skip parameter and target resolution. Accepted rows resolve targets and initial parameters, then call their handler. The handler receives readParameters for effects such as active damage that regenerate their parameters. Every evaluation retains its values and variable/function traces. Ordinary descendants drain before evaluating the next row; attached effects keep the scheduler's root placement.

The returned mutable report becomes completed only after the final row and its ordinary descendants have drained. It records skipped rows as well as executed rows. A failed continuation stops without pretending remaining rows ran. Callers must include death/phase eligibility in that decision and handle incomplete nested effects; the generic runner does not infer lifecycle outcomes from arbitrary handler results.

Tests run the original numeric/condition data for Cmd80572 and Cmd81060 through this generic runner. It matches all 64 previously captured original-expression sequences with the same explicit marker/stack adapters. A separate test confirms that an ordinary HP-event child can block a later consumption row while an attached child runs after the command. Another connects a generic BEActiveDamage row to the scheduled active-damage implementation and records changing parameters on successive hits.

This combines supported components but is not a connected original command execution. Target resolution and effect handlers are supplied. Original command construction, before/finish hooks, interrupts, delays, yielding, target retargeting and arbitrary row parameter types remain unfinished. Numeric expression coverage must not be mistaken for complete skill support or gameplay validation.

The existing Old Embers command adapter now delegates to this generic runner rather than its dedicated generator. It translates normalized effect parameters into the existing state/HP adapters, preserving the established outward step trace. Its activation additionally retains the generic command trace, including skipped rows, condition queries and parameter evaluations, so the local sequence page's raw result explains row decisions. The prepared website includes the authored row runner and expression parser in its verified runtime manifest. This integration adds no gameplay-validation claim and does not enable publication.
