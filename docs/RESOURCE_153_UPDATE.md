The changed Skill, Cmd and State rows require scoped routing and effect review. A [reproducible value-free audit](../research/evidence/pc-res153-mouchette-arachne-selected-rows.json) finds the selected Mouchette skills 122483, 122484 and 123159, Arachne Strike skill 126484, their selected command rows 122499, 123160, 133367, 134282, 134385 and 134386, and the selected states 122504, 123703, 124656, 123165, 123307, 134383, 134382, 70350 and 133368 unchanged under the same normalization. A separate [narrow replay-adapter dependency audit](../research/evidence/pc-res151-to-res153-replay-adapter-dependencies.json) checks the fields actually consumed when routing comes from replay-embedded Skill/Cmd rows. Its six code modules and BattleApi table are unchanged; the existing 6,959 State rows retain their `IsBuff` classification, the one added state classifies as neither buff nor debuff, and Constant's `DamagePer2HasState` mapping is unchanged. Run `python tools/audit_res153_replay_adapter_dependencies.py` against the ignored exports to reproduce it. The [composed resource-153 adapter gate](../research/evidence/pc-res153-replay-adapter-compatibility.json) now permits only replay-card ordinary Active **pre-hit** calculations from complete live property maps and replay-embedded routing. It does not enable HP mutation or general resource-153 simulation. The freeze path accepts this narrow build only with the matching build and adapter reports, reviewed same-session capture evidence, and an ordinary replay-card Active pre-hit scenario.

The local website and agent API remain research previews pinned to their explicitly supported older builds; the narrow resource-153 replay path is not exposed as a general calculator build. Do not label an old replay as resource 153 because it was viewed after the update. Do not freeze a resource-153 gameplay prediction using the resource-151 compatibility report. Before a resource-153 holdout, review the chosen replay's embedded routing, capture and commit a new same-process pre-battle baseline, and commit an exact deterministic prediction before revealing the recorded outcome.

No gameplay validation or publication credit is gained by this version comparison. The public website publication gate remains **NOT_READY**.
